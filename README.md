### Правілы

Рухацца: ↑, ←, ↓, → / H, J, K, L / W, A, S, D
Адкрыць ячэйку: O / Enter
Паставіць / зняць сцяг: F / Прабел
Выйсці: Q

Правілы класічнага Сапёра можаце даведацца [тут](https://minesweepergame.com/strategy/how-to-play-minesweeper.php),

## Канфігурацыя

У файле `boom/config.py` можаце рэгуляваць параметры гульні. Дакладней:

`SHOW_INFO: True / False` - ці варта паказываць лагатып і правілы гульні.
Выключайце калі хочаце вялікае поле, бо ўсё перакуліцца праз дупу

`LANGUAGE: 'be' / 'en' / 'ru'` - мова правілаў гульні
і надпісу "Перамога" (ну ці "Victory" ці "Победа" суадносна разберацеся)

`CLEAR: True / False` - ці варта ачышчаць кансоль праз кожны ход

`FIELD_HEIGHT: int` - Вышыня поля

`FIELD_WIDTH: int` - Шырыня поля

`MINES_COUNT: int` - Колькасць мін
